# plyscribe-privacy

Public web of **Plyscribe** (scoresheet photo to PGN, iPhone and iPad). To be served at
<https://plyscribe.baltajmn.dev/> by GitHub Pages from `main` behind Cloudflare (CNAME `plyscribe` to
`baltajmn.github.io`, proxied). Not published: no repository, no DNS yet.

| Path | What it is |
|---|---|
| `index.html` | What the app does and the support contact (support and marketing URL in the App Store) |
| `privacy/` | Privacy policy: the URL in the app's Settings, paywall and the App Store |
| `legal.html` | Legal notice (LSSI art. 10) |
| `ply/` | Stylesheet and icons |

Terms of use are Apple's standard EULA. The app's code lives in `~/AndroidStudioProjects/Plyscribe`.
